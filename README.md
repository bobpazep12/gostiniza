#  Гостиница "Уют" — Информационная система

Система для автоматизации учёта номеров, бронирований, гостей и платежей в небольшой гостинице.

##  Структура проекта

- `hotel_db.py` — работа с базой данных SQLite (таблицы, тестовые данные)
- `hotel_app.py` — графический интерфейс на Tkinter
- `main.py` — точка входа в программу

##  Запуск

1. Установи Python 3.8+
2. Скачай все файлы из репозитория
3. Запусти `main.py`:
   ```bash
   python main.py
